Sensor Calibration Lab

Due Fri 11 Sep, 11:59 PM  ·  Submit mystats.py + hw3.py  ·  Standard library only

Three thermocouples each took 200 readings of a reference bath held at a known 100.0 °C. Your job is to find out which sensor you'd actually trust — and to discover that "most accurate" and "most precise" are not the same sensor.

A

Build your statistics module

Write mystats.py containing mean, median, variance, stdev, and data_range. Each takes a list of numbers and returns a float.

  • Do not import statistics. Compute everything from arithmetic and loops.
  • Use the two-pass method for variance: find the mean first, then sum the squared deviations.
  • Divide by n - 1, not n. Say why in a one-line comment.
  • Every function needs a docstring stating what it takes and what it returns.
B

Load and summarize

Read sensor_readings.txt from the course page. Each line is sensor_id,reading. Import your module and print one row per sensor with all five statistics.

  • Align the columns. Two decimal places on every value.
  • Do not hard-code the number of sensors or the number of readings.
C

Accuracy versus precision

Define accuracy as the absolute distance between a sensor's mean and the true 100.0 °C, and precision as its standard deviation. Rank all three sensors on each measure separately.

The two rankings will not agree. In a comment at the bottom of your file, state which sensor you would install in a process where a slow drift is correctable but sudden jumps are not, and defend it in two or three sentences.

D

Iterative outlier rejection

Flag any reading more than three standard deviations from its own sensor's mean, discard the flagged readings, then recompute the mean and standard deviation from what's left. Repeat until a pass flags nothing.

  • Report the number of passes, the count removed per pass, and the before/after standard deviation.
  • Your loop must stop on its own. A for loop with a guessed iteration count will not receive credit.
  • Consider what happens if a pass removes every remaining point, and handle it.
Collaboration. Talk through approaches with anyone you like. Write your own code. If you use any outside source — a classmate, a website, an AI assistant — name it in a comment at the top of your file and describe what it gave you. Naming it costs you nothing. Not naming it is what gets reported.
